# 颜色怎样表达心情

核查日期：2026-11-18。用途：为 MyEnergy 的连续状态主题提供依据。本文查阅原研究与学术综述，研究结论与后续产品实现分别记录；没有验证主题的心理效果。

颜色适合辅助表达用户已记录的状态。现有证据不能据此承诺配色能改善心理健康，也不能用颜色推断用户的心情。

## 研究支持什么

Jonauskaite 与 Mohr 于 2025-01-13 发表的系统综述纳入 132 篇英文论文，研究发表于 1895—2022 年，合计 42,266 人、64 国。总体联想如下；一色可对应多种情绪。[原文](https://link.springer.com/article/10.3758/s13423-024-02615-z)

| 颜色特征 | 常见情绪联想 |
| --- | --- |
| 蓝、绿、蓝绿 | 积极、较低唤醒；蓝也有悲伤联想 |
| 黄、橙 | 积极、较高唤醒 |
| 红 | 高唤醒，兼有爱与愤怒等正负联想 |
| 浅色／深色 | 分别较常对应积极／消极 |

这些主要是抽象联想，实际感受和具体界面能否重现仍待验证。[综述的结论与限制](https://link.springer.com/article/10.3758/s13423-024-02615-z)

2020 年的跨文化原研究让 4,598 名参与者把 20 个情绪概念与 12 个颜色词匹配，覆盖 30 国、22 种母语。各国模式相似，同时受语言和地理因素影响。研究测的是颜色词的情绪含义，没有验证特定 RGB 或应用主题；中国用户仍需单独确认。[Jonauskaite 等，2020](https://journals.sagepub.com/doi/10.1177/0956797620948810)

Wilms 与 Oberfeld 的实验有 62 人，独立操纵蓝／绿／红的色相、饱和度和亮度。参与者观看 LED 色块 30 秒后评价当下感受。较鲜艳、较亮的颜色得到较高唤醒评分，皮电反应也较强；愉快度同时受这些因素及其交互影响。论文发表于 2017 年在线版、2018 年卷期，作者明确提醒：大面积自发光色块的结果能否用于其他场景仍需研究。[原文及方法、讨论](https://www.staff.uni-mainz.de/oberfeld/downloads/Wilms-Oberfeld2018_Article_ColorAndEmotionEffectsOfHueSat.pdf)

更早的 Valdez 与 Mehrabian（1994）也发现明度、饱和度很重要，但其色卡实验中，明度与唤醒呈负向关系。这与上述 LED 实验的方向不同，不能写成“越亮必然越兴奋”，更不能把其回归方程直接当作界面配色公式。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/7996122/)

Elliot 与 Maier（2014）的综述同样要求，在提出强应用建议前确认情境、边界条件及现实场景的适用性。实验中的短时感受变化也不等于长期健康收益或治疗效果。[原文摘要](https://www.annualreviews.org/content/journals/10.1146/annurev-psych-010213-115035)

## MyEnergy 可以怎样用

**设计推断，尚未验证。** 心情的愉快度与唤醒程度适合分别表达。Russell 的情感环形模型将放松放在愉快、低唤醒的一侧，将紧张放在不愉快、高唤醒的一侧。应用的“主观精力”也不能直接等同于实验中的唤醒程度。[Russell，1980 原文](https://pdodds.w3.uvm.edu/research/papers/others/1980/russell1980a.pdf)

建议保留连续渐变，但由心情主要决定表达愉快度的色相与明度，由精力另行调整颜色的鲜明程度。低精力时可以心情很好，高精力时也可能焦虑；两个输入独立保存和解释。颜色各维度存在交互，这种分工只是产品表达约定。

积极状态可同时容纳安静的蓝绿和活跃的黄橙。红色不宜固定代表消极；负面记录也应保留清楚、柔和的界面。无心情记录时显示未知／中性含义，避免仅凭精力给出积极或消极判断。继续用文字说明状态，并核查用户是否把颜色误解为建议、评分或诊断。

旧原型的“0.75 × 心情＋0.25 × 精力”、具体 RGB／HEX、约 1.6 秒过渡都没有从这些论文中获得验证。后续体验评估可比较“平静且满足”“疲惫但开心”“精力充沛但焦虑”等组合，请用户评价颜色是否贴合自身感受；可读性和舒适度另行验收。

用户回复“继续”后，应用已改为心情与精力独立的二维主题，旧加权公式已移除。实现规则见[状态主题说明](../implementation/state-theme.md)，编译、自动回归和 Mac 交互结果见[验证报告](../verification/report.md)。这些工程验证不代表主题的心理效果已获验证。
