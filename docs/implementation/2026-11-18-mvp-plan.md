# MyEnergy MVP Implementation Plan

> For agentic workers: use the available collaboration agents with executing-plans. The user has already chosen multi-agent execution; do not ask again.

**Goal:** 交付原生四端本地产品、平台适配代码与可本地联调的加密同步基础，按真实证据验收已具备条件的里程碑。

**Architecture:** Swift package 共享模型、持久化、合并和 SwiftUI；原生 iOS／macOS／watchOS 工程。独立 Node.js 密文服务和 Sign in with Apple 认证；原始健康样本留在设备。

**Tech Stack:** Swift 6、SwiftUI、HealthKit、WatchConnectivity、CryptoKit、Security、AuthenticationServices、Node.js 26、SQLite、XcodeGen。

## Global Constraints

- iOS／iPadOS 17、watchOS 10、macOS 14。
- 精力 0～100 主观自评，心情五档，与 HRV 恢复参考分开。
- 不把个人健康记录存入自建 CloudKit，不给缺失数据伪造数值。
- 无第三方 AI、订阅、广告。演示数据单独空间且明显标记。
- 应用账户、加密密钥、真实 Apple 登录和开发身份分别处理。
- 不修改兄弟 Rust 仓库。构建由 root 串行执行。
- 公共接口与算法规则完整定义在 [共享契约](contracts.md)。

Consumes：Foundation、共享契约。Produces：EnergyEntry、HabitDefinition、HabitCheckIn、AppSnapshot、SnapshotFileStore、SnapshotMerger、RecoveryAnalyzer。

- [x] 先写边界及回归用例，包含精力 0／100、无效输入、损坏文件保留、schema 版本、跨时区日期、三方冲突与删除。
- [x] 实现核心，采用显式错误而非强制解包；落盘先校验，原子写入。

```swift
let entry = try EnergyEntry(energy: 0, mood: .low)
#expect(entry.energy == 0)
#expect(throws: (any Error).self) { try EnergyEntry(energy: 101) }
```

Run：`swift test --package-path Packages/MyEnergyKit`。Expected：测试数大于 0，退出 0，覆盖上述场景。
