# 二维连续状态主题

用户于 2026-11-18 要求状态主题从消极到积极连续变化，随后要求查询颜色心理学，并明确回复“继续”实施研究后的方案。本增量只改变视觉表达，沿用原生、本地开发与独立加密同步架构，不改变用户记录或健康推断。

## 两个输入各自表达

心情 valence 为 -1～1，五档依次映射 -1、-0.5、0、0.5、1。精力 vitality 为 0～1，仅由精力除以 100 得到，不参与心情正负加权。没有心情时方向为 0；没有精力时采用中等鲜明度。两个维度分别保留 hasMood／hasEnergy 标志，未知时不画对应标记或伪造分数。

配色为产品设计推断：低精力积极用柔和蓝绿，高精力积极用杏橙／暖金；低精力消极用低饱和灰紫，高精力消极用克制红紫；中性沿鼠尾草色系变化。低精力不等于消极，高精力不等于积极，也不把主观精力当作心理唤醒度测量。

旧原型的 0.75×心情＋0.25×精力已废弃。具体 RGB 和约 1.6 秒过渡没有临床或心理学有效性证明；依据与限制见 [研究笔记](../research/color-psychology.md)。

## 动画与生命周期

每种深浅模式有六个颜色锚点：消极／中性／积极分别对应低／高精力。先在精力轴插值，再在心情轴插值。数值 RGB 通过 AnimatablePair<Double, Double> 逐帧计算并经 SwiftUI Environment 下发，不使用全局可变静态色。

Root／Watch 使用外层 host 和内层环境消费者。卡片、按钮、图表、表情、侧栏与表单沿用语义色。编辑时只有精力或心情实际变化才启动唯一 token 的预览；初次打开默认 50 的表单不覆盖原状态。取消移除自己的 token，内层预览结束可以回到外层预览；保存后按当前最新有效记录呈现。预览仅内存，不改变数据或触发同步。

自动来源为最近 24 小时内最后一条已发生的主观记录，按发生／修改时间和 UUID 稳定选择。未来、过期、非法或无记录时使用中性。Timeline 只按分钟触发新鲜度重算，每次用当前时刻过滤，避免刚保存的记录被旧 tick 当作未来数据。

账号及示例空间切换清空预览。各窗口独立协调，遵循浅深模式、增强对比度及减少动态效果；减少动态效果关闭长过渡。无循环闪烁或持续颜色轮询。示例提示在分栏内容区显示，避免遮住侧栏首项。

## 代码边界

- StateTheme.swift：StateThemeState、ThemeStateResolver、ThemeRGB、EnergyThemePalette 和状态色谱。
- StateThemeHost.swift：窗口预览栈、两个数值动画轴、时效来源及编辑器 modifier。
- StateThemeGuideView.swift：“我的”内的四组配色说明，不提供会改记录的设置。
- DesignSystem 与既有页面：通过 energyTheme 读取颜色；旧固定 EnergyStyle 已移除。

StateThemeState 对有限值只限制范围，hasMood／hasEnergy 不强制改写动画中间值；缺失输入的目标中性由 resolver 保证。这样清除心情时可以平滑退回中性，而不是跳色。

## 验收

心情独立性、未知及非法输入、24 小时边界与确定性选择；预览 token／窗口隔离、取消恢复；两个动画轴的中间帧与未知目标；21×21 的二维网格在深浅／增强对比度模式采样，正文和按钮文字至少 4.5:1，增强模式 7:1，强调色与表面至少 3:1／4.5:1；双轴连续与中性接缝。实际 Mac 视觉和原生编译证据另记验证报告，不把数值测试当作完整设备体验验收。
