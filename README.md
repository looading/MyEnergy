## 当前已确认的需求

1. 产品工作名为 MyEnergy，在本目录开发。
2. 仅面向 Apple 用户，覆盖 macOS、iPhone、iPad 和 Apple Watch。
3. 支持同一产品账号的数据互联。
4. 多个 agent 分工协作，以 PMP 的启动、规划、执行、监控、收尾过程组管理交付。

具体功能、版本下限、数据同步实现和发布范围均以设计评审结果为准。文档中的建议不等于用户已批准的需求。
